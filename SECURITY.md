# Security policy

The [cplieger security policy](https://github.com/cplieger/.github/blob/main/SECURITY.md) applies to this repository, with one difference: two major versions get security fixes.

| Version | Security fixes |
| --- | --- |
| `v3` | yes |
| `v2` | yes |
| `v1` | no |

To report a vulnerability, select this repository's **Security** tab, then **Report a vulnerability**, as that policy describes.
